# Эмпирические интервалы прогноза

Для каждого сегмента из `result.csv` добавлены границы на основе 10-го и 90-го процентилей знаковой ошибки `факт − прогноз`. Границы ограничены диапазоном от нуля до номинальной толщины. [Интервалы по сегментам](../reports/uncertainty_intervals.csv)

В кейсе 1 процентили рассчитаны по 508 историческим отложенным остаткам. Перенос границ проверен на 53 поздних измерениях соседних участков. В кейсе 2 остатки взяты из проверки с удержанием целой магистрали. При расчёте границ обе магистрали имеют равный вес, как и кампании внутри магистрали. В диагностике процентили одной магистрали применены к остаткам другой. Модели внешних фолдов обучались на противоположной магистрали, поэтому это приближённая диагностика переноса интервала. [Фактическое покрытие и ширина](../reports/uncertainty_validation.csv)

Уровни 10% и 90% описывают используемые процентили. Покрытие на закрытом тесте неизвестно. При переносе на новую магистраль оно зависит от того, насколько распределение новых ошибок похоже на контрольное.

После воспроизведения основных отчётов запустите из корня проекта:

```bash
python analysis/defense_intervals.py
```
