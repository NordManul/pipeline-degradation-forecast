# E04: прогноз по сопоставленным дефектам

`matching.py` фиксирует пары по геометрии и положению швов, без использования
толщины в стоимости соответствия. `models/matched_rates.py` использует только
допустимые пары из обучающего фолда. До сопоставления удаляются обе кампании
вне train, а модель повторно проверяет принадлежность обоих концов каждой пары.

Сначала рассчитывается медианная знаковая скорость по каждой 10-метровой ячейке,
затем медиана по ячейкам: плотный кластер дефектов не получает сотню голосов.
Предусмотрены глобальная скорость, локальная со стягиванием к глобальной и
отдельный вариант с неотрицательной скоростью. Последний — явно обозначенное
физическое допущение; отрицательные измеренные изменения исходных пар сохраняются.

Локальное ядро 300 м обращается только к сохранённым обучающим скоростям.
Это оценщик по train, а не заранее вычисленный признак с метками соседей.
Валидационные метки и пары не входят в ядро. Общие фолды имеют буфер 100 м,
а признаки прошлого ВТД — радиус 50 м.

Если калибровочных ячеек меньше 10, используется явно отмеченный резерв:
медианная скорость изменения ячеек с наблюдаемым прошлым ВТД. При прогнозе
ячейки без измеренного якоря используется общий train-only `fallback_mm`.
Сырой прогноз передаётся общему оценщику для одинаковой отсечки до номинала.

Применение к дате обучающей кампании допускается только с явным
`spatial_development=True`. Это вспомогательная пространственная диагностика.
Для case2 E04 недоступен: к 2022-07-01 разрешённой пары кампаний нет.
Число найденных пар само по себе не является точностью сопоставления или прогноза.
