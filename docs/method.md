# Методика

## Целевая величина

Простой участок разбивается от начала на полуоткрытые интервалы по 10 м. Для метки берётся минимум валидной зарегистрированной остаточной толщины по точкам ВТД внутри интервала. Точка на правой границе всего участка исключается. Ячейка без записи ВТД имеет неизвестную метку. Все модели оцениваются на одинаковой маске наблюдаемых меток и дают прогноз для всей сетки. [Правила сетки и метки](../configs/data_contract.yaml)

Время отсчёта — начало целевого дня по Москве. Для датированных источников проверяются время события и доступность записи. При отсутствии даты публикации используется дата записи. Паспорт и профиль рельефа используются как заданные статические источники. Технические снимки агрегируются по одному на наблюдаемый день. Доля покрытых дней входит в признаки.

## Кейс 1. Прогноз по прошлому ВТД

В обучении 561 валидная ячейка MAIN-2 из перехода 23.09.2018 → 06.07.2022. В целевом прогнозе за якорь взято ВТД от 06.07.2022. Для примеров используются режим до даты примера, рельеф, толщина и локальный контекст прошлого ВТД. Дополнительные признаки берутся из отдельных внутренних дефектов прошлого ВТД, включая минимум по дефектам глубиной от 20% в радиусе 30 м и расстояние до него.

Два регрессора обучаются на зарегистрированной толщине в миллиметрах. GAM здесь состоит из сплайнов по признакам и регуляризованной линейной регрессии. Второй предиктор — CatBoost. Их ограниченные паспортным диапазоном прогнозы усредняются поровну. Для ячеек без своего прошлого замера используется произведение номинала на медиану отношения измеренной и номинальной толщины в обучении. На целевой трубе свой якорь есть у 508 из 525 ячеек.

В 177 из 357 исторических ячеек с измерениями в обе даты зарегистрированный минимум вырос. Такой рост оставался даже у части строгих геометрических пар. Состав и округление ВТД различаются между кампаниями. Поэтому модель строится на уровне зарегистрированной толщины и использует все валидные метки, включая ячейки с ростом зарегистрированного минимума. [Аудит кампаний и пар](https://github.com/NordManul/pipeline-degradation-forecast/blob/codex/connectivity-check/reports/2026-11-14-case1-measurement/README.md)

В пространственной проверке удерживаются четыре непрерывных блока MAIN-2 с буфером 100 м. Преобразования и резерв для отсутствующего якоря подбираются только внутри train. Метрика по 508 наблюдаемым ячейкам цели объединяет отложенные прогнозы. Pearson r на четырёх блоках лежит в диапазоне от −0,006 до 0,638. Поздние ВТД двух соседних участков от 01.12.2023 открываются после обучения и прогноза. Это отдельная проверка переноса между кампаниями. [Метрики](../reports/metrics.csv)

Воспроизведена смесь с 25% Huber на статистиках прошлого ВТД без числа записей. Она повышает Pearson² с 0,32294 до 0,33463 на истории и с 0,17200 до 0,17546 на объединённых поздних метках. Внутри поздних участков после центрирования Pearson² меняется с 0,11939 до 0,11779. Из шести тончайших поздних ячеек Huber в смеси находит две, выбранная GAM/CatBoost — три. У варианта «уровень + профиль» Pearson² 0,32275 на истории и 0,20935 на позднем ВТД, а полнота поздних тонких ячеек также снижается до двух из шести. Для сдачи выбран исходный профиль GAM/CatBoost. ## Кейс 2. Перенос между магистралями

По уточнению правил кейса 2 разрешены более поздние ВТД других магистралей. Снимок донорского пула зафиксирован до 01.01.2025. В обучение входят 1 080 ячеек четырёх кампаний MAIN-2 и MAIN-3. MAIN-4 целиком исключена из донорского пула. Для каждого донора окно режима заканчивается до собственного ВТД, для запроса MAIN-4 — до 01.07.2022. Агрегаты режима используются в контрольном CatBoost. Финальная модель использует рельеф и паспортные параметры из перечня входов кейса 2 в ТЗ. [Контракт переноса](../contracts/case2/retrospective.yaml) · [Исходное ТЗ](task)

1. XGBoost на относительной координате и высоте над медианой рельефа предсказывает `−ln(измеренная_толщина / номинал) / возраст_в_годах`. Толщина восстанавливается как `номинал × exp(−возраст_в_годах × прогноз_скорости)`. Суммарные веса всех четырёх донорских кампаний равны.
2. KNN оценивает толщину по 12 соседям из донорского пула на относительной координате. Веса соседей убывают с расстоянием.
3. В каждом простом участке профиль KNN приводится к среднему и стандартному отклонению профиля XGBoost. Для обоих расчётов используется полная 10-метровая сетка прогнозов. Два профиля усредняются поровну, итог ограничивается паспортным диапазоном.

Каждый внешний фолд удерживает всю магистраль со всеми её ВТД. Реальные минимумы применяются при вычислении метрик после расчёта профиля. Средние считаются сначала по кампаниям каждой магистрали, затем поровну по магистралям. В таблице приведён seed 42, которым создаётся файл сдачи.

| Модель | Pearson² MAIN-2 | Pearson² MAIN-3 | Средний Pearson² | Средняя MAE, мм | Средний recall тонких 10% |
| --- | ---: | ---: | ---: | ---: | ---: |
| CatBoost с весами из прошлого выпуска | 0,00465 | 0,09251 | 0,04858 | 0,35118 | 25,9% |
| XGBoost | 0,01706 | 0,17293 | 0,09500 | 0,32330 | 31,5% |
| XGBoost + KNN 50/50 | **0,03600** | **0,19599** | **0,11600** | 0,31961 | 27,8% |
| Random Forest | 0,01061 | 0,14501 | 0,07781 | 0,31958 | **36,7%** |

На seed 42, 123 и 2024 средний Pearson² смеси составляет 0,11600, 0,11136 и 0,11261. На каждом seed он выше одиночного XGBoost на обеих магистралях. При seed 42 знаковая корреляция положительна на всех четырёх кампаниях, а MAE ниже прежнего CatBoost на каждой кампании. Две отложенные магистрали ограничивают надёжность оценки, MAIN-3 и MAIN-4 относятся к одному направлению DIR-3. TECH покрывает 13,3% дней истории запроса и одинаков для всех ячеек одного участка. Пространственный сигнал итоговой модели дают координата и высота, их вклад в прогноз сам по себе не устанавливает механизм утонения. ## Приоритетные ячейки

В каждом участке отсортированы ячейки по возрастанию предсказанной толщины. При равенстве используется номер ячейки. В кейсе 1 ранжирование берётся из GAM/CatBoost, в кейсе 2 — из Random Forest на тех же двух признаках и годовой логарифмической потере. На MAIN-3 лес нашёл пять из десяти тончайших ячеек, смесь XGBoost/KNN — три. В список входят первые 53 и 148 ячеек соответственно. Поле `ranking_thickness_mm` содержит прогноз ранжирующей модели. В `result.csv` для кейса 2 используется смесь XGBoost/KNN. [Ранжированный список](../reports/priority_segments.csv)

Pearson² здесь — квадрат корреляции. По знаковому Pearson r проверяется направление связи, по MAE — величина ошибки в миллиметрах. Все контрольные кампании были доступны при исследовании альтернатив. Команда отдельно зафиксировала метрики закрытой проверки для файла сдачи с указанным SHA-256.
