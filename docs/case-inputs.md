## Содержимое каждого `case1/` и `case2/`

- `prepared.joblib` — словарь с каноническими train/predict frame, exposure, allowlist,
  общими фолдами, cutoff, конфигурацией, хешами контрактов и исходных CSV.
- `train_frame.csv.gz`, `predict_frame.csv.gz`, `exposure.csv.gz` — те же основные таблицы.
- `folds/fold_N_train.csv.gz`, `folds/fold_N_valid.csv.gz` — точные общие ключи и fallback,
  обученный только на train соответствующего фолда.
- `final_train.csv.gz`, `final_predict.csv.gz` — входы окончательного fit и запроса;
  fallback здесь обучен на полном разрешённом train.
- `cleaning_audit.csv.gz` — построчные причины исключения/маскировки с исходным файлом,
  номером строки и SHA-256. `cleaning_summary.csv` — агрегированные количества действий.
- `summary.json`, `folds.json`, `fallback.json`, `input_manifest.json` — метаданные.

В train-таблицах остаётся полная геометрическая сетка. **Для `fit` выбрать только `observed=true`.**
Для predict передавать все запрошенные ячейки; y и служебную маску не передавать как признаки.
Fallback в исходном `prepared['train_frame']` намеренно не вычислен на всех метках:
используйте `model_views`, чтобы не получить утечку в OOF.

```python
import joblib
from pipetwin.case_data import model_views

package = joblib.load("artifacts/official-inputs-20261114-v1/case2/prepared.joblib")
train, valid, fallback_info = model_views(package, fold_number=0)
fit_rows = train.loc[train.observed].copy()
X_valid = valid.drop(columns=["y_mm", "observed", "coverage_status", "label_available_at"], errors="ignore")
# model = make_model(... exposure=package["exposure"],
#                    cutoff_exclusive=package["cutoff_exclusive"],
#                    feature_columns=package["feature_columns"])
# model.fit(fit_rows, fit_rows.y_mm.to_numpy())
# prediction_mm = model.predict(X_valid)
```

Для финального fit/request вызвать `model_views(package)` без номера фолда. Общий резерв:
`nominal_mm * median(train_y_mm / train_nominal_mm)`. В каждой проверке медиана считается заново
по её train. Ни validation-метки, ни метки будущих кампаний в неё не входят.

Каждое окно экспозиции имеет собственный `exposure_id`; история одного ID на разных
горизонтах не смешивается. Неизвестные дни содержат `observed=false`, NaT доступности и NaN
физических каналов. Нулевая подача — наблюдение. Температурная политика нового пути
`observed_endpoints` сохраняет допустимые отрицательные °C; старый фильтр <=0.001 остаётся
отдельным явным legacy-сценарием.

## Проверки

Новые тесты проверяют не только даты таблиц, но и инвариантность признаков/прогнозов
при порче всех будущих ВТД и расхода кейса 2, дату выпуска запаздывающих измерений,
агрегацию прошлого ВТД до вычисления минимумов, train-only fallback и буферы через ID.
На первом полном запуске основной ветки с этим слоем: 103 теста рабочего дерева пройдены,
включая 5 локальных тестов ещё не опубликованной модели скоростей E04.

Сетка и маска скрытого скоринга остаются предварительными до эталонного шаблона.
Очистка не объявляет отсутствие дефекта здоровой стенкой, не придумывает эпоху 2014
и не превращает сомнительные УЗТ/купоны в обучающие метки.
