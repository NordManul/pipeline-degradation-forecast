# Очистка данных и единицы измерения

Исходные файлы находятся в [data/raw](../data/raw). При воспроизведении создаётся `cleaning.csv` с количеством исключённых строк и замаскированных полей по файлу и правилу. SHA-256 исходных таблиц записаны в [отчёте запуска](../reports/summary.json).

| Источник или поле | Единица и обработка |
| --- | --- |
| Паспортная длина | км в источнике, умножается на 1 000 для сетки в м |
| `Distance_adjusted` и рельеф | м от начала простого участка |
| `d_mm` в TECH | м по совпадению с паспортом, несмотря на название поля |
| Толщины ВТД | мм |
| `Defect Depth in %` | доли в ВТД 2018, проценты остальных известных кампаний. Проверка остатка по номиналу и глубине с допуском 0,05 мм |
| `watercut` | проценты. Деление на 100 распространяется и на исходные значения меньше единицы |
| `p`, `p_start`, `p_end` | атм. Тип давления и вид атмосферы требуют уточнения для физического расчёта |
| `q` | м³/сут |
| `q_oil` | т/сут. Для проверки баланса масса переводится в м³/сут через положительную плотность |
| `q_gas` | тыс. м³/сут. Приведение к м³/сут множителем 1 000 на условиях источника |

По полям давления и газа пока нельзя однозначно определить абсолютное давление и расход газа при рабочих условиях. Проверенные агрегаты жидкостного режима, обводнённости, скорости и температуры входят в модель кейса 1 и контрольный CatBoost кейса 2. В финале кейса 2 профиль определяется геометрией. [Контракт единиц](../contracts/units.yaml)

## Несостыковки, влияющие на решение

- Таблица входов кейса 2 в ТЗ перечисляет паспорт, профиль трассы и TECH. В отдельном абзаце сказано «только на основании технологического режима эксплуатации». В реализации паспорт и профиль считаются допустимыми входами из таблицы. ВТД целевой магистрали исключено. [Исходное ТЗ](task)
- Кампания 2014 на MAIN-1 предшествует паспортному вводу. Эпоха металла не установлена, MAIN-1 исключена из донорского пула.
- УЗТ `1250009583` показывает 11,04–12 мм при паспортном номинале 4,5 мм. Назначение точек и привязка не подтверждены. УЗТ и купонные замеры исключены из построения признаков и меток.
- Снимок TECH `1250009583` за 07.10.2018 исключён по совместной аномалии расхода и давления. Отрицательные расходы, невалидные доли, конфликтующие дубли и записи вне геометрии обрабатываются явными правилами. Валидные каналы сохраняются, когда ошибка относится к отдельному полю.
- Кампании ВТД различаются составом зарегистрированных дефектов и округлением глубины. Пригодные минимумы не отбрасываются из-за знака измеренной разности.
- Порог обнаружения дефектов, маска покрытия, идентификация длинных дефектов между ячейками и официальный шаблон остаются открытыми. Использованные полуоткрытые границы и точечная привязка описаны в контракте.
