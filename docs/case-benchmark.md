# Единое сравнение по контракту ментора

```powershell
python -m pipetwin.pipeline prepare-cases --output artifacts/official-inputs-20261114-v2
python -m pipetwin.pipeline case-benchmark --prepared artifacts/official-inputs-20261114-v2 --output artifacts/official-benchmark-20261114-v2
```

Обе команды отказываются перезаписывать существующую папку. Запуск публикуется
атомарно после завершения обоих кейсов, построения графиков и проверки повторной
загрузки всех моделей. При изменении YAML-контрактов подготовку нужно повторить.

Общие фолды и цели берутся из `prepared.joblib`. Нового разбиения для удобства
конкретной модели нет. Fit получает только наблюдаемые цели. Warm-модели скорости
обучаются на измеренных якорях; пакет агента проверяет это внутри своего fit.
Прямые модели толщины (`ridge_direct`, E02) используют все валидные train-цели:
для их обучающей цели не требуется вычитать ненаблюдаемый якорь.
Все warm-модели используют один train-only fallback на строках без якоря.
Это уточнение нового benchmark; прежние исторические результаты не смешиваются с ним.

В `configs/case_benchmark.yaml` заранее перечислены 18 базовых вариантов и две
смеси: GAM/CatBoost 50/50 и GAM/физический scale-гибрид 75/25. Для case1 добавлены
шесть E04-вариантов из `configs/matching.yaml`; для case2 разрешённого перехода нет.
Смеси усредняют прогнозы компонентов после общей отсечки. Отдельно сохраняется
среднее сырых выходов компонентов для диагностики. Веса не обучаются на OOF.
Оба E03-сценария неизвестных дней сравнивает второй агент; в этом запуске явно
фиксирован `observed-only`.

E04 пересчитывает соответствия отдельно внутри каждого train-фолда. Исходные
файлы для matching повторно проходят тот же cleaner; их SHA должны совпасть с
подготовленным пакетом. Итоговые пары, якоря и unmatched-записи сохранены.

Выбор: положительный Pearson r, затем максимальный r², затем минимальная MAE;
если положительных r нет — минимальная MAE. Выбор фиксируется по общему OOF до
прогноза целевых труб. Отсечка одинакова: `[0, nominal_mm]`. Исходные выходы некоторых
базовых моделей уже имеют внутреннюю нижнюю границу 0 — raw означает выход модели
до **общей** отсечки, не отмену её внутреннего определения.

Каждая модель возвращает все ячейки, а scorer использует единую observed-маску:
561 метку case1 и 372 case2. Сохраняются общий и пофолдовый OOF, метрики до/после
отсечки, параметры, train/valid sample_id, fallback, времена fit, сдвиг признаков,
полные прогнозы и joblib. Корреляция константы — undefined, не ноль и не идеальный балл.

Выходной профиль проверяется отдельно: полностью насыщенный или постоянный
прогноз отмечается `forecast_review_required`. Такой флаг не меняет автоматически
заранее заданное правило выбора. Физически допустимый диапазон не доказывает точность.
`selected_provisional_predictions.csv` содержит 2000 предварительных ячеек;
это ещё не официальная сдача. Шаблон и итоговая маска организаторов отсутствуют.

`comparison.png` показывает сравнение на пространственных фолдах; `forecast_profiles.png`
— профили без неизвестных целевых ВТД. Самостоятельный HTML-отчёт объединяет их.
Ни один график не выдаёт пространственную проверку одной трассы за независимую
проверку будущего или другой трубы. Единого конкурсного балла пока нет.
