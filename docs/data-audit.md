# Аудит входных данных

Проверены обе PDF и все строки шести CSV. Ключевые расхождения по ID, датам, дистанции и толщине перепроверены независимыми сводками. Исходники лежат в `D:/Загрузки`. Таблицы содержат географические координаты, хотя описание кейса указывает, что координат нет. Хранить исходники и результаты с геопривязкой локально. После углублённого ревью полный реестр открытых вопросов вынесен в [inconsistencies.md](inconsistencies.md), доказательства единиц и формулы — в [units-and-dimensions.md](units-and-dimensions.md).

## Что проверено

| Наблюдение | Действие при разработке |
| --- | --- |
| У 16 простых ID четыре группы `MAIN` и три направления. `1250009583` — единственный простой ID без ВТД, у него есть УЗТ. Три простых ID с повторами входят в один `MAIN`. | Получить уровень зачётного ID и crosswalk. Ни отсутствие ВТД у одного ID, ни количество повторов сами по себе не определяют состав сдачи. |
| Для простых участков длины POT в км после ×1000 согласуются с TECH `length` и ВТД `section_length`; максимумы профиля отличаются до 0.047 м. При локальной сетке на всех 16 участках получилось бы 4 668 сегментов. Для `MAIN-2` общая сетка длиной 5 786.5 м дала бы 579 сегментов, а сумма локальных сеток — 580. Отдельное поле «Длина по верификации» пусто у всех 16. | Пробная геометрия допустима для аудита. Для результата нужна эталонная сетка и, при склейке, порядок и ориентация участков. Привязывать наблюдения к общей координате до нарезки. |
| `Distance` и `Distance_adjusted` равны во всех 48 291 строках. `Distance_raw` может быть общим километражем, например 21 814.73 м на простом участке длиной 129.1 м. 4 локальных координаты отрицательные, 247 выше паспортной длины, все 251 отмечены `is_beyond_pot`. | В прототипе использовать локальную скорректированную дистанцию. Проверить происхождение поправки и наличие будущих якорей. Отдельно сверять точки у границ, таблицу исключённых строк и влияние на minima. |
| ВТД на 2014-12-28, 2018-09-23, 2022-07-06, 2023-08-12, 2023-12-01 содержит соответственно 13 511, 2 496, 28 665, 201, 3 418 строк. Один простой ID даёт 26 110 строк из 28 665 за 2022 год. | Считать метрики по трубе/кампании и покрытию. Для обучения по дефектам проверять веса по участкам и кампаниям. |
| Для 2 464 полных строк 2018 года использование формального процента даёт расхождение с измеренным остатком до 4.1976 мм. При чтении поля как доли остаток совпадает с точностью до 0.004 мм. В остальных датах деление на 100 согласуется с остатком до 0.04 мм. В 3 465 полных строках 2023 года абсолютная глубина согласуется с разностью толщин до машинной точности. | Хранить исходное поле, нормализовать по кампании и проверять реконструкцию. Основной пробный таргет брать из `Residual Wall Thickness` при допустимом типе дефекта. Заполнять пропуски расчётом только по подтверждённому правилу и учитывать отдельно. |

Отдельно оценивать перенос при коротком покрытии и чувствительность к предположениям о режиме в пропусках. |

## Вопросы организаторам

1. Какие два зачётных ID, на каком уровне иерархии, какой сценарий и точная дата T для каждого? Нужен `sample_result.csv` или эталонный список ключей, включая последний сегмент, и порядок склейки простых участков по потоку. Последняя дата TECH сама по себе не задаёт T.
2. Как формируется целевая толщина и маска скоринга? Нужны правила для участков без регистрации дефекта, порогов обнаружения и покрытия, типов дефектов, геометрии длинного дефекта, крайних координат и точек вне участка. Как агрегируют две оценки Pearson² и обрабатывают константные серии?
3. Какие признаки разрешены для прогноза от ввода до ВТД? Паспорт и профиль перечислены, а текст отдельно ограничивает прогноз технологическим режимом. Уточнить профиль, купоны, перенос обученных параметров и использование технологических данных с той же календарной датой, что T.
4. Какая дата ввода и номинальная стенка соответствуют пяти участкам с ВТД 2014 года? Есть ли история замен/ремонтов и типы приборов с погрешностью и порогом регистрации по кампаниям? Подтвердить локальную дистанцию и происхождение её коррекции, доли в слое 2018 года и смысл расхождения УЗТ с POT.
5. Нужен словарь единиц и происхождения TECH и REPCORR, особенно P, T, обводнённости, дозировки ингибитора, CO₂ и `pit_corrosion_intensity`. Уточнить, что означают нули в фактическом давлении и температуре, а также какие из 495 купонов допустимо привязать.
