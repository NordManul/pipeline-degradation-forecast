# E03 — скорость, интеграл потери и гибридные модели

E03 работает в сценарии между ВТД и сравнивает шесть предикторов на одинаковых ключах.
Входы, правила фильтрации цели и локальная сетка 10 м совпадают с E02.

| Предиктор | Расчёт |
| --- | --- |
| `persistence` | Перенос последнего измерения |
| `constant_rate` | Общая положительная скорость, оценённая робастно по обучающему фолду |
| `parametric_rate` | Положительная скорость как функция ежедневного режима |
| `ml` | Random Forest прогнозирует знаковое изменение толщины в мм/год |
| `hybrid_scale` | Параметрическая скорость с регуляризованным положительным множителем по сегменту |
| `hybrid_residual` | Параметрический прогноз и Random Forest для знаковой годовой остаточной ошибки |

Параметрическая модель использует выражения

```text
r(day) = exp(a + beta · z(day))             мм/год
loss   = sum(r(day) × days(day) / 365.25)   мм
latent_thickness = max(0, previous_thickness - loss)
```

В `z` входят доля воды, средняя температура концов участка, `log(1 + v / (1 м/с))`
и коэффициент заполнения. Импутация и стандартизация обучаются только на наблюдавшихся
днях участков обучающего фолда. Это параметрическая модель с физическим ограничением
знака скорости. Её параметры калибруются на доступных данных. Применимость NORSOK M-506
и de Waard–Milliams требует дополнительных подтверждённых входов, включая параметры CO₂.

Начальная толщина взята из прошлого измерения. Название `latent_thickness_mm` обозначает
монотонную часть предиктора, привязанную к этому измерению. Ошибки прибора и истинная
потеря металла отдельно по этим двум кампаниям не идентифицированы.

Робастная функция ошибки pseudo-Huber имеет масштаб 0.5 мм. При вычислении ошибки
используются исходные наблюдаемые разности, включая увеличение измеренной толщины.
Штраф L2 на коэффициенты скорости равен 0.25, на коэффициенты масштабной поправки — 1.
Штрафы добавляются отдельно от робастной ошибки данных. Ошибка данных усредняется по
числу обучающих сегментов. Границы log-скорости и коэффициентов сохранены в `report.json`.
Стандартизованные каналы ограничиваются диапазоном [-5, 5], log-множитель гибрида — [-5, 5].
Это зафиксированные вычислительные ограничения первого эксперимента.

Для `hybrid_scale` множитель равен `exp(g(segment))` и применяется к интегралу потери.
Он сохраняет неотрицательную потерю. В `hybrid_residual` лес обучается на
`(observed_thickness - latent_thickness) / horizon_years` внутри обучающего фолда.
Итоговый наблюдаемый прогноз может превышать прошлое измерение. Все предикторы имеют
нижнюю границу 0 мм. Достижение нуля означает исчерпание стенки в принятой модели.

Лес использует 200 деревьев, глубину 4, минимум 8 строк в листе и seed=42. В признаках
доступны прошлое ВТД и блоки E02. ID и абсолютная координата исключены. При включении
рельефа добавляются его признаки и взаимодействия. Поток вдоль возрастающей координаты
в этом эксперименте является явно выбранным сценарием.

Каждые сутки представлены один раз. Последний снимок дня используется на интервале
`[дата предыдущего ВТД, дата цели)`. Неизвестные дни остаются отмеченными как неизвестные.
Для них доступны два сценария

- `train-median`, по умолчанию — физические каналы заполняются медианами обучающих
  наблюдений, скорость интегрируется по всему календарному горизонту.
- `observed-only` — интеграл учитывает только дни с записью TECH. Пропуски отдельных
  каналов в этих записях заполняются обучающими медианами. Это чувствительность к
  неполной экспозиции, а не оценка фактического отсутствия коррозии в пропусках.

Длинные пропуски не заполняются переносом последней записи. Доля дней с записью и с
полным набором физических каналов выводится в `exposure_summary.csv`.
Преобразования единиц и температурный сценарий наследуются от E02.

Установка и основной запуск из корня репозитория

```powershell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m pip install --no-deps -e .
.venv/Scripts/python.exe -m pytest -q -W error
.venv/Scripts/python.exe -m pipetwin.e03 --output-dir runs/e03-main --late-date 2023-12-01
```

Также доступна команда `pipetwin-e03`. Для Linux путь интерпретатора — `.venv/bin/python`.
Каждый запуск записывается атомарно в новый каталог. Варианты чувствительности запускаются
с `--missing-policy observed-only` и `--terrain-direction increasing` соответственно.
Дополнительные параметры доступны через `--help`.

В каталоге результата сохраняются

- `predictions.csv` с наблюдаемыми и монотонными компонентами прогнозов, фолдами и типом проверки.
- `metrics.csv` с r, Pearson², MAE, RMSE, bias и recall@10% по участкам и фолдам.
- `exposure_summary.csv` с покрытием TECH и интегралами потери в миллиметрах.
- `fits.csv` с числом обучающих/проверочных сегментов и временем обучения.
- `report.json` с настройками, коэффициентами скорости, оптимизатором, аудитом, версиями и SHA256 входов.
- `models.joblib` с моделями, обученными на всех разработочных сегментах 2018→2022.

Вызов сохранённого предиктора

```python
from pathlib import Path
import joblib
from pipetwin.sources import read_sources
from pipetwin.features import build_features
from pipetwin.models.physics import build_exposure
from pipetwin.e03 import predict_e03

bundle = joblib.load("runs/e03-main/models.joblib")
sources = read_sources(Path("data/raw"))
frame, audit = build_features(sources, "2022-07-06", "2023-12-01")
frame = frame.loc[frame.previous_thickness_mm.notna()]
exposure = build_exposure(sources["tech"], frame.id, "2022-07-06", "2023-12-01")
predictions = predict_e03(bundle, frame, exposure)
```

Для рельефного варианта следует передать тот же профиль, направление и радиус,
которые сохранены в конфигурации модели. Даты определяют новый горизонт прогноза.

Первая пространственная проверка использует MAIN-2, переход 2018→2022, 355 общих
наблюдаемых сегментов, пять непрерывных блоков каждого простого участка и буфер 50 м.
Все преобразования и поправки обучаются заново внутри каждого фолда.

| --- | --- | --- | --- | --- |
| Перенос ВТД | 0.4908 | 0.6407 | 0.3294 | 0.1085 |
| Общая скорость | 0.4954 | 0.6428 | 0.3233 | 0.1045 |
| Параметрическая скорость | 0.4954 | 0.6428 | 0.3233 | 0.1045 |
| ML | 0.4096 | 0.5760 | 0.1682 | 0.0283 |
| Гибрид с множителем | 0.4953 | 0.6426 | 0.3234 | 0.1046 |
| Гибрид с остаточной поправкой | 0.4096 | 0.5760 | 0.1682 | 0.0283 |

Поздняя проверка 2022→2023 выполнена на 52 общих сегментах двух коротких участков
той же магистрали. Все кандидаты и настройки зафиксированы до её оценки.

| --- | --- | --- | --- | --- |
| Перенос ВТД | 0.4725 | 0.6232 | 0.1268 | 0.0161 |
| Общая скорость | 0.4680 | 0.6174 | 0.1268 | 0.0161 |
| Параметрическая скорость | 0.4680 | 0.6174 | 0.1268 | 0.0161 |

У параметрической скорости коэффициенты режима сильно стянуты к нулю, поэтому результат
близок к общей скорости. Гибрид с остаточной поправкой близок к самостоятельному ML.
На пространственных блоках лучший Pearson² остаётся у переноса прошлого ВТД.
Поздняя проверка показывает снижение MAE примерно на 10.2% у ML и остаточного гибрида.
Она относится к одной трассе и малой выборке после аудита данных. Поздняя кампания уже
просматривалась также во время приостановленной разработки E01, поэтому независимость
от общей исследовательской работы ограничена.

В сценарии `observed-only` MAE остаточного гибрида на поздней кампании составляет 0.4236 мм,
Pearson² — 0.0362. Эти результаты описывают чувствительность к пропускам при фиксированных
настройках. Улучшение от самой физической компоненты относительно ML пока мало.

В дополнительном сценарии рельефа `increasing` MAE остаточного гибрида составляет 0.4041 мм
на пространственных блоках и 0.4345 мм на поздней кампании, Pearson² — 0.0320 и 0.0264.
На поздней кампании этот сценарий уступил базовому составу признаков.

Проверки охватывают перевод суток в годы, високосный год, отсутствие двойного учёта суток,
оба сценария пропусков, положительность скорости, исчерпание стенки, исходные знаковые
изменения измерений, импутацию внутри обучения, исключение будущего TECH, сохранение
и восстановление моделей, одинаковые ключи сравнения и прерванную публикацию артефактов.
