# Сравнение моделей для защиты

В таблицах используются результаты на одинаковых метках внутри каждого контрольного набора. Колоночные графики на слайдах округляют значения до трёх знаков. [Базовые метрики](../reports/metrics.csv) · [Закрытые оценки файла сдачи](../configs/closed_scores.yaml)

## Кейс 1

| Модель | Pearson², 508 исторических меток | Pearson², 53 поздние метки |
| --- | ---: | ---: |
| Прошлое ВТД | 0,140 | 0,024 |
| Экстраполяция годовой потери | 0,303 | 0,042 |
| LSTM | 0,241 | 0,025 |
| 75% основной смеси + 25% Huber с числом записей ВТД | **0,356** | 0,141 |
| CatBoost RMSE | 0,294 | **0,214** |
| GAM + CatBoost 50/50 | 0,323 | 0,172 |

У LSTM на поздних ВТД знаковая корреляция отрицательная (r = −0,157). Смесь превосходит обе простые базы на двух проверках по Pearson² и MAE. На большей части позднего контроля (48 из 53 меток) Pearson² одного CatBoost составляет 0,098 против 0,095 у смеси. Huber с числом записей снижает Pearson² на поздней проверке. Для сдачи выбран компромисс по двум проверкам. [Табличные модели и нейросети](https://github.com/NordManul/pipeline-degradation-forecast/blob/7f49078/reports/2026-11-15-final-round/README.md) · [Huber и отдельный CatBoost](https://github.com/NordManul/pipeline-degradation-forecast/blob/844a013/src/pipetwin/agent2_physics/FINAL_SELECTION.md#кейс-1)
