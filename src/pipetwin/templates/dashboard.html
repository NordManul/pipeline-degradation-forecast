Воспроизвести отчёт и файл сдачи

Из корня репозитория · Python 3.12 · CPU x86-64 · новый каталог вывода

python -m pip install -c requirements-lock.txt -e ".[test]"
python -m pipetwin.pipeline --output artifacts/replay
python -m pytest -q

В новом каталоге появятся dashboard.html, result.csv, шесть PNG, SVG, контрольные прогнозы, данные профилей, метрики и сводки.
