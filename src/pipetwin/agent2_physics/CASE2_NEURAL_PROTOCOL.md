# Проверка моделей локальной последовательности для кейса 2

Цель — минимальная толщина в 10-метровых сегментах MAIN-4 на 01.07.2022.
Разрешённый ретроспективный пул других труб и функции подготовки и оценки
берутся из прежней проверки. Во внешней проверке по очереди удерживаются
MAIN-2 и MAIN-3 целиком со всеми кампаниями. Гиперпараметры фиксированы до
запуска. Проверка исследовательская, так как эти две MAIN уже использовались
при разработке.

- Окна по 11 точек, два варианта шага: 20 и 50 м, радиус 100 и 250 м.
  Используется статический высотный профиль сетки своей секции. Высоты
  в окне приведены к высоте центра. Точки за границей отмечаются маской
  доступности. ВТД и соседние целевые значения в окна не входят.
- Контроли: прежние XGBoost-15 и Random Forest на координате и высоте.
  В каждой ширине сравниваются XGBoost на развёрнутом окне, MLP на тех же
  признаках, 1D-CNN и однослойный трансформер с двумя головами внимания.
  Отдельная проверка переносимости — фиксированная смесь 75% прежнего XGB
  и 25% каждой нейросети. Вес смеси общий и заранее выбранный.
- У всех моделей одна цель `-log(y_mm / nominal_mm) / horizon_years`,
  равные веса кампаний, seed 42, 123, 2024. Нейросети: 50 эпох, minibatch
  64, AdamW с 0,003 и weight decay 0,02, dropout 0,15. Преобразования
  обучаются только на наблюдаемых строках train, без early stopping
  по внешним меткам. Настройки и маски сохраняются.
- Метрики считаются отдельно по кампаниям и затем с равным весом MAIN.
  Для смены кандидата при фиксированном seed 42 требуем положительный r
  во всех четырёх кампаниях, больший средний Pearson² на обеих MAIN,
  преимущество в общем макро-Pearson² минимум при двух из трёх seed и
  рост макро-MAE не более 0,02 мм. Список тонких участков оценивается
  отдельно через recall тонких 10%.

История TECH доступна по простому участку. Использовать её как локальную
последовательность для каждого сегмента означало бы повторить один сигнал
во всех 1 475 строках MAIN-4. Эксперимент проверяет пространственную
последовательность реального профиля.
