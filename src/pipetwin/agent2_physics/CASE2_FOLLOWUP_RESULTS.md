# Проверка предложений для кейса 2

Для квадрата корреляции рекомендован **XGBoost с 15 листьями**. Для
приоритизации обследований по тонким участкам и меньшей ошибки в мм
остаётся **Random Forest**. Победителя одновременно по всем трём метрикам
в эксперименте не было. Проверка использует две известные магистрали,
целиком исключаемые из fit по очереди. Скрытое ВТД MAIN-4 недоступно.

Средние считаются сначала по датам каждой MAIN, затем с равным весом MAIN.
Средний r² — среднее квадратов корреляции кампаний. Полная таблица содержит r²
всех моделей. Сравнение верхних пяти строк использует одни и те же относительную
высоту, положение на участке, веса кампаний и цель
`-log(y_mm / nominal_mm) / horizon_years`. Проверены также потеря в мм/год
и доля номинала в год. За установленным XGBoost закреплены параметры в runner.

На MAIN-3 recall тонких 10% снизился с 50% до 40%. На трёх seed средний
r XGBoost-15 составил 0,266–0,269, у леса 0,190–0,241. Оба дали
положительный r во всех четырёх кампаниях. Смесь повысила средний r над лесом
при каждом seed. При исходном seed 42 она уступила лесу по MAE и recall.

## Реализация предложений

- Использован XGBoost 3.4.1 из окружения. LightGBM отсутствует. Смесь с
  фиксированными 40/30/30 использует заранее выбранный XGBoost с 7 листьями.
- Частичное объединение оценивает регуляризованные общие эффекты, поправки
  исходных простых участков и усадку пяти зон относительной длины. На новой
  трубе используются общие эффекты и переносимые зоны. Интервалы по дисперсии
  исходных остатков и участков покрыли 89–98% у варианта с двумя признаками,
  при средней ширине 0,68–2,24 мм по кампаниям.
- Гауссовский процесс использует RBF по относительной дистанции и линейное
  ядро по высоте. Угол дефекта отсутствует для целевых 10-метровых сегментов.
  Длинное ядро сделало профиль более гладким по среднему перепаду соседних ячеек
  в каждой кампании. Интервалы P10–P90 этого варианта дали 88–98% покрытия
  при ширине 0,68–2,28 мм. Их покрытие для MAIN-4 неизвестно. Модель и параметры
  априорной ковариации зафиксированы, дисперсия шума оценена по train.
- RankSVM строит пары внутри простого участка и кампании. Изотоническая
  калибровка скорости выполняется только на train. Spearman и перепад
  соседних предсказаний сохранены в диагностике.
- CatBoost с `init_model` проверен как перенос между кампаниями обучающей
  магистрали. Удерживаемая MAIN по-прежнему отсутствует в fit. На стороне,
  где доступна одна кампания, это обычный CatBoost. Для проверки дообучения
  на второй независимой трубе и оценки на третьей нужны дополнительные ВТД.
- В аддитивном варианте исходный E03 интегрирует положительную скорость
  по истории с `train-median`. Лес учит остаточную потерю в мм/год.
  Итоговая поправка ограничена ±0,5 мм. Корреляция выросла относительно
  физического prior с −0,106 до 0,239, но лес без prior сохранил меньшую MAE.
- CNN/LSTM пропущены после проверки числа разных историй. 1 080 меток имеют
  всего 15 последовательностей режима, в каждом обучающем фолде их 7–8.
  У 1 475 целевых сегментов одна последовательность. Для этого эксперимента
  копии истории по сегментам не дают независимых временных наблюдений.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
python -W error -m pipetwin.agent2_physics.case2_followup --strict-reference artifacts/agent2_physics/shared-inputs-d443e4f/case2/prepared.joblib --output artifacts/agent2_physics/case2-followup-new
```

В `artifacts/agent2_physics/case2-followup-final/` сохранены 59 конфигураций,
100 обучений на фолдах, метрики и прогнозы всех моделей на двух удержаниях.
`case2_candidate.csv` содержит лес для всех 1 475 целевых сегментов,
`case2_correlation_candidate.csv` — XGBoost с диапазоном 2,664–3,506 мм.
Все 254 теста прошли с `-W error`. Ключи, даты, маски, воспроизводимость четырёх финальных моделей и совпадение
метрик двух запусков проверены. Старый кандидат Random Forest воспроизведён.
Все данные целевого запроса по-прежнему ограничены 01.07.2022.
