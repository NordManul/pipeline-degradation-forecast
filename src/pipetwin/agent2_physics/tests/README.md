# Тесты второго агента

Здесь должны появиться содержательные тесты моделей из `contracts/model-api.md`.
Начать с синтетических frame/exposure: календарь, пропуски, два окна одного ID,
train-only preprocessing, строгие cutoff, отсутствие якоря, cold start и сериализация.

Сейчас executable-тестов в этой папке нет. Команда pytest по этой папке до их
добавления закономерно не соберёт тестов; это не успешная проверка реализации.
