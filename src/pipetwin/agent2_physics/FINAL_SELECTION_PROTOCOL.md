# Финальная проверка относительно `main`

База — релиз `e84586b` с GAM/CatBoost 50/50 в кейсе 1 и CatBoost
с весами магистралей и кампаний в кейсе 2. Повторить релиз из его исходников.
Сравнивать метрики кандидатов только при совпадении состава проверочных
кампаний и воспроизведении метрик CatBoost на каждой из четырёх дат.

Кейс 1 оценивать отдельно на 508 исторических ячейках цели и 53 поздних
метках двух соседних участков. Для поздней проверки дополнительно смотреть
метрику внутри большего участка и полноту тонких 10%. Зафиксированный
профиль GAM/CatBoost остаётся основой итогового файла при разногласии
исторической и поздней проверок либо снижении полноты тонких мест.

Кейс 2 проверять на удержании всей MAIN-2 или MAIN-3 с прежними метками.
Зафиксировать XGBoost-15 с двумя признаками как контроль. Повторить лес
для отдельного списка тонких мест и CatBoost из `main` как контроль релиза.
Для XGBoost проверить только следующие изменения по одному:

- Ограничение годового log-rate по квантилям 1/99% или 5/95% каждой
  обучающей кампании, а также понижение веса дальних отклонений от её
  медианы через MAD и округлённый порог 2,5 робастного стандартного отклонения.
- Удвоение веса нижнего дециля относительной толщины внутри кампании и
  обратный вес от числа ВТД с наблюдаемым минимумом в той же ячейке.
  Нормировать изменённые веса так, чтобы сумма по кампании сохранялась.
- 80, 240 и 320 деревьев вместо 160. Отдельно оценить монотонное снижение
  log-rate с ростом относительной высоты как ограниченную гипотезу о низинах.

Дополнительная гипотеза из завершённой широкой сетки. KNN на относительной
координате предсказывает форму с высокой корреляцией на MAIN-3. Проверить
смесь с XGBoost, используя 25% и 50% KNN. Перед смешиванием привести
среднее и стандартное отклонение KNN к соответствующим значениям XGBoost
по полному прогнозу простого участка или кампании. Этот шаг использует
только прогнозы, включая ячейки без метки. Для постоянного профиля KNN
выравнивание даёт среднее XGBoost. Прямой KNN остаётся контролем.

Использовать seed 42, 123 и 2024. Для замены требуется положительный r на
всех четырёх кампаниях, выигрыш по r в трёх из четырёх на seed 42, рост
Pearson² на обеих MAIN и общий рост хотя бы на двух seed. Допустимое
ухудшение макро-MAE — 0,02 мм. При нескольких прошедших вариантах
использовать наибольший макро-Pearson² при seed 42. Веса, границы цели и
повторяемость ячеек вычисляются исключительно на обучении.

Итоговый кандидат объединяет 525 значений кейса 1 из релизного вывода и
1 475 значений выбранной модели кейса 2. Сверить все ключи, физические
границы, порядок строк релизного файла и воспроизведение выхода из модели.
Для кейса 2 отдельно сохранить 148 наименьших прогнозов леса.
