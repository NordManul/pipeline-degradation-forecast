# Проверка качества входов для двух кейсов

База общего конвейера eb152f3. Оценка по минимуму зарегистрированной толщины
в 10-метровой ячейке. Маски, ключи, отсечки и общий scorer сохраняются.
Порог/маска скрытой оценки, метод прибора, эпоха MAIN-1, УЗТ и срок
действия TECH не считаются подтверждёнными. Единицы из контракта уже
применены общим cleaner. Исходные файлы сохраняются.

1. Аудитировать причины очистки, состав записей и типы минимумов ВТД,
   различия номиналов, количество записей на ячейку, переходы между
   кампаниями и нерегулярность истории TECH. Не считать карантином
   исключение по дате. Проверять качество измерения и пригодность для
   переноса раздельно.
2. Кейс 1. Из предыдущего ВТД построить устойчивые локальные сводки
   (минимум, нижний квартиль, медиана, число наблюдений). Сравнить
   исходные записи и сопоставимый поднабор отдельных внутренних
   дефектов с глубиной ≥15%. Числа/квартили считаются только по ВТД-якорю.
   Проверить ограниченный Ridge, обычную регрессию и Huber, обучение
   только на наблюдаемых якорях и обучение с явно отсутствующими якорями.
   Сохранённые пространственные фолды 2022 оцениваются на 508 ячейках цели
   и 561 ячейке всей кампании. Проверка 2023 — 53 метки соседних участков,
   используется только для оценки. Контроль — текущий прямой GAM/CatBoost.
   Проверить также исключение числа записей и фиксированные смеси 75/25
   контроля с Ridge или Huber на старых сводках, с числами записей и без.
   Эта добавка — второй исследовательский прогон после просмотра первой
   серии. Вес одинаков для всех вариантов поправки.
3. Кейс 2. Сравнить наблюдаемые обучающие минимумы всех типов, минимум
   по коррозии, минимум по отдельным внутренним дефектам, и поправку
   цели по номиналу самого дефекта (при прежней оценке толщины в мм).
   Поднаборы меняют только fit. Обследования одной MAIN полностью
   убираются из fit. Сравнить простой Ridge, ограниченный Ridge, Ridge
   на центрированных скоростях, XGBoost на том же наборе и действующий
   CatBoost. Наборы: координата/высота, локальный рельеф, добавление
   режима с раздельными признаками наблюдаемости. Покрытие TECH и шаг
   времени описываются без восстановления неподтверждённой истории.
   Если поднабор пуст хотя бы в одной обучающей части, фиксируется размер
   пула и двустороннее сравнение для этой политики считается недоступным.
4. Критерий кандидата кейса 1: прирост Pearson² на 508 ячейках,
   положительный r, выигрыш по r минимум в трёх из четырёх блоков,
   Pearson² late ≥ контроля и MAE на обеих проверках не хуже контроля
   более чем на 0,01 мм. Кейс 2: положительный r на всех четырёх
   кампаниях и Pearson² выше XGBoost на обеих MAIN в среднем по
   кампаниям, макро-MAE не хуже более чем на 0,02 мм.
   Скрытые метки недоступны; использованные проверки исследовательские.
