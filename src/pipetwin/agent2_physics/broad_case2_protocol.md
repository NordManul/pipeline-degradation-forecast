# Поиск моделей для восстановления кейса 2

Цель MAIN-4 на 01.07.2022. Обучающий пул других магистралей включает поздние
кампании, разрешённые пользователем. Общая очистка, сетка и функция метрик
сохраняются. Неразрешённая эпоха MAIN-1 и спорные УЗТ исключаются.

В каждом направлении переноса целиком удерживается MAIN со всеми датами.
Обучение на оставшейся MAIN сравнивается в нескольких вариантах: все кампании,
первая, последняя и все с равным весом кампаний. Последний вариант применяется
к моделям с поддержкой веса. Доноры не содержат ВТД целевой MAIN-4.

Сетка скрещивает составы признаков, способы кодирования потери и семейства
регрессоров. Простые эвристики, E02, E03 при двух политиках неизвестной
экспозиции и два фиксированных средних прогнозов дополняют сетку. Новые
группы признаков описывают форму профиля до 250 м в каждую сторону, распределение
известной экспозиции и взаимодействия рельефа с режимом. Это прокси, а не
измеренные локальные скорости или механистическая формула коррозии.

Оценка выполняется отдельно по MAIN × дате, на всех общих наблюдаемых метках.
Неопределённые корреляции сохраняются в исходных метриках. Для рейтинга
считаются минимум signed r по четырём кампаниям и среднее signed r с равным
весом двух MAIN. Модели с константой хотя бы в одной кампании получают
нулевой положительный вклад этой кампании и не проходят критерий выигрыша.
Сравнение в первую очередь по минимуму signed r, затем по среднему signed r,
затем по MAE. Контроли сравниваются также по MAE, RMSE и recall тонких 10%.
В рейтинг отбора не входят диапазоны запроса MAIN-4.

Критерий устойчивого преимущества: положительный r в каждой кампании, средний
r и минимальный r выше CatBoost на канонических признаках с относительной
годовой потерей, средний MAE по MAIN ниже этого же CatBoost и средний recall
тонких 10% не хуже. Это критерий исследования. Повторно использованные две
MAIN не дают независимой оценки перебора и не заменяют скрытое ВТД.

В первой серии высота и координата вошли в один блок position. Во второй серии
добавляется проверка каждой из двух переменных отдельно. Гиперпараметры прежние.
Предупреждения о сходимости записываются и исключают вариант из отбора.

Отчёт сохраняет все конфигурации, результаты по кампаниям, рейтинг и прогнозы
лидеров по корреляции и MAE, в том числе среди прошедших критерий выигрыша.
Для каждого лидера проверяется воспроизведение
из сохранённых весов. Семейство, набор признаков, целевая переменная и состав
обучения фиксируются в конфигурации до расчёта метрик. Исторический строгий
кейс 2 и официальный экспорт ведутся отдельно.
