# Проверка кандидатов перед сдачей кейса 2

Сформированы два выхода для MAIN-4 на 01.07.2022. `result.csv` содержит
толщину XGBoost на всех 1 475 сегментах. `dangerous_segments.csv` содержит
148 сегментов с наименьшей толщиной по Random Forest, то есть ⌈10% × 1 475⌉.
Результат относится к кейсу 2. Скрытое ВТД MAIN-4 отсутствует.

## 1. Устойчивость к seed

Pearson² вычисляется отдельно по каждой кампании, затем усредняется внутри
магистрали. MAIN-2 и MAIN-3 имеют одинаковые веса.

| Seed | RF r² | XGB r² | Разница |
| ---: | ---: | ---: | ---: |
| 42 | 0,07781 | 0,09500 | +0,01719 |
| 123 | 0,06049 | 0,09609 | +0,03560 |
| 2024 | 0,06597 | 0,09969 | +0,03372 |
| Среднее ± выборочное SD | 0,06809 ± 0,00885 | 0,09693 ± 0,00246 | +0,02884 ± 0,01013 |

Указанный критерий пройден: 0,01013 < 0,02884 / 2 = 0,01442.
Эта проверка измеряет влияние seed на этих данных. Независимых магистралей две.

## 2–3. Удержание магистралей и кампаний

В каждой ячейке таблицы RF → XGB, Pearson², seed 42.

| Удержанная кампания | Целая MAIN | Одна кампания | Кампания с удалением совпадающих сегментов из train |
| --- | ---: | ---: | ---: |
| MAIN-2, сентябрь 2018 | 0,00609 → 0,00361 | 0,02751 → 0,02991 | 0,00095 → 0,00125 |
| MAIN-2, июль 2022 | 0,01218 → 0,01573 | 0,05411 → 0,03640 | 0,00998 → 0,04606 |
| MAIN-2, декабрь 2023 | 0,01355 → 0,03185 | 0,00090 → 0,00263 | 0,00944 → 0,00651 |
| MAIN-3, август 2023 | 0,14500 → 0,17293 | 0,14500 → 0,17293 | 0,14500 → 0,17293 |
| Побед XGB по r² | 3/4 | 3/4 | 3/4 |

Обычный Leave-one-campaign-out оставляет 394, 409 и 89 наблюдений совпадающих
10-метровых ячеек в train для трёх дат MAIN-2. В дополнительном прогоне эти
ключи полностью исключены из train, маска проверки осталась прежней.
Соседние сегменты и принадлежность к одной магистрали остаются возможным
источником зависимости. Перенос на новую трубу характеризует удержание MAIN.
Особенность декабря 2023: при удержании одной кампании signed r отрицателен
у обоих вариантов. Без удаления совпадений r составляет −0,030 у RF и
−0,051 у XGB. Поэтому 3/4 по квадрату здесь включают один результат с
обратным ранжированием. В удержании целой MAIN у обеих моделей r положителен
на всех четырёх кампаниях.

## 4–7. Базовые прогнозы, смеси и калибровка

| Модель, seed 42 | Средний Pearson² | MAE, мм | Recall тонких 10% |
| --- | ---: | ---: | ---: |
| Паспортный номинал | не определён | 1,394 | 10,6% |
| Единая скорость | не определён | **0,310** | 10,6% |
| Random Forest | 0,07781 | 0,320 | **36,7%** |
| XGBoost | 0,09500 | 0,323 | 31,5% |
| 50% RF / 50% XGB | 0,09820 | 0,319 | 28,4% |
| 60% RF / 40% XGB | 0,09699 | 0,319 | 28,4% |
| XGB, 10-й квантиль толщины | 0,06348 | 0,594 | 14,5% |
| XGB с изотоникой | **0,11034** | 0,371 | 28,5% |

Прошлого ВТД целевого участка в кейсе 2 нет, поэтому persistence по фактической
толщине неприменим. Константные ранжирования дают около 10% recall с учётом
размеров выборок и ничьих. RF превосходит этот контроль на всех четырёх
кампаниях. XGB превосходит его в среднем и на трёх кампаниях, а в 2018
году набирает 8,8% против 10,2%. По MAE обе модели лучше номинала, а единая
скорость остаётся сильнее. Сравнение численных r² с константой невозможно,
поскольку дисперсия константного прогноза равна нулю.

Фиксированная смесь 50/50 дала +0,00320 по r² и −0,00424 мм MAE относительно
XGB. При этом она выиграла по r² у XGB на двух кампаниях из четырёх и
уступила RF по recall. Обе смеси сохранены как альтернативные CSV.
Изотоника повысила средний r² главным образом за счёт MAIN-3
(0,173 → 0,217), ухудшив r² на трёх остальных кампаниях и MAE на всех
четырёх. Для неё использованы только внутренние прогнозы с удержанием
целого простого участка. Квантиль обучен с alpha=0,90 на скорости
утонения, поскольку зависимость толщины от скорости убывающая.

Выбор двух выходов опирается на устойчивость XGB к seed, 3/4 положительных
выигрышей по r² при удержании MAIN и лучший recall RF. Если считать только
средний r² на этой проверке, лидирует изотоника, затем смесь 50/50.

## 8–9. Экспорт и воспроизводимость

- `result.csv` содержит 1 475 уникальных строк, ID 1250009583, номера
  0–1474 и ровно `id,segment_id,thickness_pred`.
- `dangerous_segments.csv` содержит 148 строк в порядке роста
  предсказанной толщины. При равенстве сортировка по номеру сегмента.
- Оба выхода восстановлены из закреплённых моделей предыдущего запуска.
  Проверены исходные прогнозы, ключи и сохранённые значения. Максимальная
  погрешность повторной загрузки округлённого XGB CSV — 4,94·10⁻¹⁰ мм.
- Сырой XGB на MAIN-4 даёт 2,664–3,506 мм. Из 1 475 сегментов 0 за
  пределами [2,25; 4,725] мм и 0 изменены ограничением [0; 4,5] мм.
  Диапазон прогнозов проверен, входной сдвиг по возрасту, номиналу и режиму
  сохраняется. Признаки и история запроса совпали с исходным срезом.

Результаты достаточны для описания сделанного выбора по доступным данным.
Четыре кампании относятся к двум магистралям. Сравнение этих моделей не
устанавливает потолок качества и не измеряет точность скрытого кейса 2.


Файлы выполненного прогона находятся в `artifacts/agent2_physics/case2-release-final/`.

прогнозы и исходные хеши. Для повторного запуска нужны модели предыдущего
эксперимента и проверенный пакет строгого среза.
