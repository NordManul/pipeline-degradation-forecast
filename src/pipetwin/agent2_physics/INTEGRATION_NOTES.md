# Запросы на изменения общего конвейера

Владелец заполнения — второй агент. Общий конвейер изменяет основной агент.

Пока запросов нет. При добавлении указать файл/интерфейс, необходимое изменение,
причину, совместимость с контрактом 1.0.0 и проверку, подтверждающую необходимость.

Предусмотренные подключения основного агента: канонические frame/exposure,
общий fallback, передача контекста в фабрику, имена `agent2_*` в реестре,
общие фолды/оценка/графики, включение новой папки тестов в общий проверочный запуск.
До этого тесты пакета запускаются явно командой из README этой папки.
Эти подключения пока не считаются реализованными.
