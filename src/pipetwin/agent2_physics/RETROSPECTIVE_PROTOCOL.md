## Проверка, зафиксированная до нового запуска

Использовать стандартный sklearn LeaveOneGroupOut по MAIN. Все кампании
магистрали уходят в одну проверочную группу. Доступны только две чистые MAIN;
поэтому результаты остаются исследовательскими, а не доказательством переноса
на третью. Предыдущие исследования уже использовали эти метки.

Метрики считать общей функцией отдельно для каждой пары MAIN × дата.
Общий Pearson по смешанным датам не использовать для выбора: он может отражать
различие средних между кампаниями вместо профиля одной трубы.

Фиксированные кандидаты без подбора seed/гиперпараметров:
`persistence`, `global_rate`, `gam`, `catboost`, существующий `e02_terrain`,
`agent2_constant_rate`, `agent2_hybrid_residual`.
Для физики использовать явный сценарий `train-median`; для остаточной поправки
включить `train-bounded` guard. Это выбор по предыдущей диагностике, а не
заявление, что неизвестная история восстановлена точно. Номинальная нормировка
остаётся выключенной. Seed=42, остальные параметры прежние.

CatBoost заранее обозначен основным кандидатом предыдущей диагностики, но
не получает статус доказанного победителя автоматически. Для рекомендации
переноса требуются положительный r и преимущество над простыми контролями
в обоих направлениях; все кампании, MAE, RMSE и recall thin-10% публикуются.
Если направления противоречат друг другу, универсальный победитель не объявляется.

После проверки обучить каждого кандидата на всех 1 080 валидных метках и
сохранить прогнозы 1 475 ячеек MAIN-4, веса и replay. Общий clipping и метрики
используются без изменений. Это материалы для интеграции основным агентом,
не официальный result.csv и не новая модель кейса 1.
