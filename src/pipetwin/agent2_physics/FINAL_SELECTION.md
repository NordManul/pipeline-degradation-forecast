База — `main` на `e84586b436651e5a2f0dde5f7cd1662b2212692b`. Запуск
релизного конвейера воспроизвёл `result.csv` и `reports/metrics.csv`
по SHA-256. Итоговый кандидат использует **GAM/CatBoost 50/50 для кейса 1**

ячеек используется закреплённый Random Forest. [Протокол проверки](FINAL_SELECTION_PROTOCOL.md)

Смесь с выравниванием по участку выиграла у XGBoost-15 по знаковому r
во всех четырёх кампаниях при seed 42, а по Pearson² — на обеих MAIN при
каждом seed. Макро-Pearson² на seed 42/123/2024 составил 0,11600, 0,11136
и 0,11261 против 0,09500, 0,09609 и 0,09969. На 94 метках MAIN-3 смесь
дала 0,19599, XGBoost — 0,17293, CatBoost из `main` — 0,09251.
На MAIN-2 самый большой прирост пришёлся на декабрь 2023, 0,03185 → 0,07266.
MAE смеси уменьшилась относительно XGBoost и CatBoost на каждой из четырёх
кампаний при seed 42. Для тонких сегментов используем отдельный список.
Варианты очистки и настройки деревьев не прошли критерий замены XGBoost.
Усечение по 5/95% дало почти такой же recall, как лес на seed 42. Лес
нашёл больше тонких ячеек на обследованиях 2018 и июля 2022, а по MAIN-3
нашёл пять из десяти, как и усечённый XGBoost. Для ранжирования сохраняем
ранее проверенный выход леса.

Калибровка изотоникой давала макро-Pearson² 0,11034 на этих двух MAIN, с
ухудшением MAE до 0,371 мм и падением Pearson² в трёх кампаниях MAIN-2.
Сглаживание ±30 м давало 0,10450 при seed 42, с падением MAIN-3 до 0,14255.
Сохраняются все четыре донорские кампании. XGBoost использует
`position_fraction` и `altitude_relative_m`, прогнозирует годовой log-rate
и восстанавливает толщину экспонентой. Прямой KNN использует 12 соседей
по относительной координате с весами по расстоянию. По каждому простому
участку среднее и стандартное отклонение прогноза KNN масштабируются
к соответствующим значениям прогноза XGBoost. Затем два профиля
усредняются поровну. Выравнивание использует полную сетку прогнозов.
MAIN-4 оценивается по данным до 01.07.2022, более поздние ВТД других труб
допустимы для обучения.
Конкурсное качество определится по скрытому ВТД MAIN-4.

## Воспроизведение на ветке агента 2

Из корня репозитория в активной среде с зависимостями проекта и XGBoost 3.4.1.
Архив `main` фиксирует выпуск и его порядок строк. Новый строгий пакет
нужен только для сверки признаков и отсечки запроса.

```powershell
New-Item -ItemType Directory -Path 'artifacts/agent2_physics' -Force | Out-Null
$base = 'artifacts/agent2_physics/main-e84586b'
git archive --format=zip "--output=${base}.zip" e84586b
Expand-Archive -LiteralPath "${base}.zip" -DestinationPath $base
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
$strict = 'artifacts/agent2_physics/final-strict'
python -m pipetwin.pipeline prepare-cases --output $strict
python -W error -m pipetwin.agent2_physics.final_selection --main-dir $base --strict-reference "$strict/case2/prepared.joblib" --output artifacts/agent2_physics/final-selection-new
```

Проверенный результат в `artifacts/agent2_physics/final-selection-hybrid/`.
`result.csv` содержит 2 000 строк в порядке `main`, 525 прогнозов кейса 1
из релиза и 1 475 прогнозов смеси XGBoost/KNN. Проверены совпадение 45 входных
признаков и 10 603 календарных дней целевого запроса со строгим срезом,
границы толщины, ключи и повторная загрузка моделей. `dangerous_segments.csv`
содержит 148 ключей по лесу. `case2_metrics.csv` и `case2_by_seed.csv`
содержат полный финальный эксперимент, `summary.json` — параметры экспорта.
Два независимых запуска дали одинаковые CSV по SHA-256. Толщины кейса 2
в пределах 2,485–3,424 мм воспроизведены из весов в отдельном процессе.
С `-W error` прошли 33 теста `main` и 273 теста ветки агента 2 в окружении
без необязательного CPU PyTorch.
