# Кейс 2: ограниченная проверка переноса, этап 3

Протокол записан до запуска новых вариантов. Это продолжение исследования на
уже просмотренных пространственных фолдах, **не новая независимая проверка**.
Контракт 1.0.0, общий пакет `shared-inputs-d443e4f/case2`, MAIN-2 2018,
372 наблюдаемые метки; будущие кампании и спорные эпохи не используются.

## Гипотезы

1. **Масштабирование потери относительно номинала.** Обучить скорость в мм/год
   при опорном номинале — медиане номиналов только обучающей части. Для строки
   умножить скорость на `nominal_mm / train_reference_nominal_mm`. Аналогично
   масштабировать годовую остаточную поправку. Это гипотеза пропорциональной
   потери, а не установленный закон коррозии. При одинаковом номинале 8 мм у
   всех обучающих строк варианты должны совпасть в OOF. Проверка переносимости
   на 4,5 мм тогда невозможна, даже если запросные прогнозы отличаются.
2. **Локальный рельеф вместо признаков принадлежности к трассе.** Использовать
   только общие `slope_50m`, `lowpoint_depth_m` для остаточной поправки. Сравнить
   подписанный уклон с `abs(slope_50m)` (инвариантность к направлению отсчёта).
   Радиус признаков 50 м меньше общего буфера 100 м. Положительная поправка
   к величине потери (`hybrid_scale`) проверяется как отдельная гипотеза.

Скорость, импутация, масштабирование и поправки обучаются внутри общего
фолда. Параметры регуляризации прежние; подбор сетки, перебор seed и
автоматическое повторение неудачных гипотез отсутствуют.

## Фиксированные варианты

| Вариант | Модели | Признаки поправки | Масштабирование номинала |
| --- | --- | --- | --- |
| references | persistence, global_rate, GAM, CatBoost, constant_rate, positive_rate, guarded hybrid_residual | общий allowlist | нет |
| nominal-relative | constant_rate, positive_rate, guarded hybrid_residual | общий allowlist | относительно train |
| terrain-signed | guarded hybrid_residual | уклон, глубина понижения | нет |
| terrain-symmetric | guarded hybrid_residual | модуль уклона, глубина понижения | нет |
| terrain-symmetric-relative | guarded hybrid_residual | модуль уклона, глубина понижения | относительно train |
| terrain-scale | hybrid_scale | уклон, глубина понижения | нет |
| terrain-scale-relative | hybrid_scale | уклон, глубина понижения | относительно train |

Все семь конфигураций запускаются при обеих политиках неизвестных дней.
`observed-only` остаётся основной заранее выбранной политикой,
`train-median` — чувствительность к неизвестной истории, не второй шанс
выбрать красивый прогноз. Охрана остаточной поправки: train-bounded, z=3,
минимальный относительный масштаб 1e-6; Ridge alpha=100.

## Критерий полезного результата

Основной ранжирующий критерий контракта — положительная корреляция, затем
её квадрат, затем MAE. Дополнительно для утверждения о **существенном
вспомогательном выигрыше** требуются одновременно:

- положительный OOF r выше, чем у global_rate, GAM и CatBoost;
- MAE хотя бы на 5% ниже лучшего MAE этих трёх обучаемых контролей;
- положительный r как минимум на трёх из четырёх фолдов;
- меньший MAE, чем у того же лучшего по общему MAE контроля, минимум на
  трёх фолдах.

Порог 5% — инженерное правило этого исследования, не официальный скоринг
и не статистическая значимость. Четыре блока одной кампании не считаются
четырьмя независимыми трубами. Публикуются все варианты и все фолды, включая
отрицательные результаты; целевой диапазон прогнозов не участвует в выборе.
Если ни один вариант не проходит, существенный выигрыш не заявляется.

Общий `run_case` сохраняет собственный предварительный выбор внутри каждого
запуска. Он не означает победу среди конфигураций и не создаёт подтверждённую
модель кейса 2. Ни один результат этого этапа не докажет высокую точность на
MAIN-4 без разрешённой независимой проверки.
