# Кейс 1. Признаки соседних ячеек прошлого ВТД

Рекомендация для кейса `1250022871` на `2023-12-01` — оставить веса смеси
GAM/CatBoost 50/50 и предпочесть повторное обучение с двумя группами признаков.
Исходная смесь остаётся контрольным прогнозом, а поправка у границ без повторного
обучения — более простой резерв. Поправка для ячеек без измерения ухудшила оценку.

### Что добавлено

- **Границы ячейки.** Минимальная остаточная толщина среди записей прошлого
  ВТД в интервале сегмента, расширенном на 2 м с каждой стороны. Второй признак
  — абсолютное расстояние от центра сегмента до ближайшей записи с этим минимумом.
- **Локальный контраст.** Минимум собственного сегмента в прошлом ВТД минус
  медиана минимумов измеренных соседних ячеек в пределах 50 м по центрам.
  Собственная ячейка исключена из медианы.
- **Фиксированное правило у границы.** Из базового прогноза вычитается четверть
  положительной разницы между прошлым минимумом своей ячейки и минимумом в
  расширенном интервале. Правило применяется при наблюдаемом собственном минимуме.
- **Правило для пропусков.** К общему резервному прогнозу для ячейки без замера
  добавляется половина разницы между локальной медианой и типичной медианой таких
  ячеек из обучающей части, с пересчётом через номинал. Эта поправка проиграла.

Сохранены исходная сетка 10 м, целевые метки, четыре фолда с буфером 100 м,
общая маска и исходные параметры GAM/CatBoost. В расчёт признаков входят записи
прошлой кампании по тому же участку, доступные строго до даты примера. Все
четыре варианта повторного обучения используют измеренный собственный якорь в
train, а для отсутствующего якоря берут общий train-only резерв. Параметры двух
правил и радиусы заданы до сравнительного запуска. Базовые OOF и прогноз на дату
кейса сверены с ранее сохранёнными значениями с абсолютным допуском 1e−11.

### Как читать выигрыш

Обе группы признаков повышают знаковый Pearson r на двух фолдах из
четырёх, простое правило — на трёх. При поочерёдном исключении каждого фолда
из подсчёта метрики прирост Pearson² у лучшего варианта остаётся положительным
на всех ячейках (от 0,011 до 0,034) и на целевом участке (от 0,012 до 0,036).
В трудном четвёртом блоке `r` исходной смеси равен 0,032, смеси с двумя группами
признаков — 0,025, простого правила — 0,071. Единый сдвиг на одну ячейку не
восстанавливает связь на этом блоке. Результат поддерживает использование
локального контекста, но сам по себе не устанавливает величину ошибки координат.

В исторической оценке целевого участка собственный якорь есть у 321 из 508
размеченных ячеек. В запросе на дату кейса он есть у 508 из 525 ячеек. При
приближённой перевзвешенной оценке с последней долей якорей на исторических
метках лучший вариант также лидирует: Pearson² 0,275 против 0,240, MAE
0,394 против 0,402 мм. Такая проверка меняет только веса двух групп покрытия.
Точность будущего прогноза и эффект смены кампании она не измеряет.

Все числа относятся к одному историческому переходу 2018→2022. Дата прогноза
для сдачи — 1 декабря 2023 года. Целевое ВТД скрыто, поэтому прирост на нём
не подтверждён. По общему OOF MAE улучшилась на 0,005 мм; наиболее заметный
эффект виден по корреляции и поиску тонких сегментов.

### Воспроизведение

Из корня репозитория, после `prepare-cases` и `case-benchmark`:

```powershell
python -m pipetwin.case1_heuristics --prepared artifacts/official-inputs-20261114-v2/case1/prepared.joblib --reference artifacts/official-benchmark-20261114-v2/case1 --output artifacts/case1-heuristics-repeat
```

В `forecast_provisional.csv` сохраняются 525 сегментов с исходной смесью и
всеми вариантами. `combined_context` — рекомендуемый вариант, `edge_rule` —
простая поправка у границ. Итоговый файл сдачи формируется отдельно, после
сверки сетки с шаблоном организаторов. Полные прогнозы и OOF находятся в
локальном `artifacts/case1-heuristics-20261114-v2`; компактные метрики и график
сохранены в этой папке отчёта. Два запуска дали идентичные метрики и прогнозы.
Общий набор тестов — 193 пройденных.
