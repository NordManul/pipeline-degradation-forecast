# LightGBM, XGBoost и модели последовательностей

Для сдачи рекомендован [текущий result.csv](../2026-11-14-case1-measurement/result.csv).
В этом прогоне обе контрольные модели повторили значения в файле на всех 2 000
ключах с точностью до округления CSV. Контрольные фолды, метки, даты, маски
и прогнозы сверены с предыдущим сравнением. Все 203 теста прошли.

## Кейс 1

Историческая оценка на 508 размеченных ячейках целевого участка из кампании
06.07.2022. Использованы те же четыре пространственных фолда с буфером 100 м.
`Late` — 53 метки от 01.12.2023 на двух соседних участках MAIN-2. Эти метки
присоединены после обучения и прогноза. Контроль — смесь прямых прогнозов
GAM/CatBoost 50/50 с признаками сравнимых дефектов и локального контекста.

| Модель | Исторический Pearson² | MAE, мм | Найдено из тонких 10% | `Late`, знаковый Pearson r | `Late`, Pearson² | `Late`, MAE, мм |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **Текущая смесь GAM/CatBoost** | **0,323** | **0,358** | **42,0%** | **0,415** | **0,172** | **0,357** |
| LightGBM | 0,201 | 0,388 | 40,4% | 0,376 | 0,141 | 0,360 |
| XGBoost | 0,210 | 0,385 | 38,4% | 0,373 | 0,139 | 0,390 |
| LSTM | 0,241 | 0,393 | 32,9% | −0,157 | 0,025 | 0,778 |
| 1D-CNN | 0,204 | 0,393 | 37,3% | −0,163 | 0,027 | 0,647 |
| Transformer Encoder | 0,194 | 0,394 | 36,5% | −0,271 | 0,074 | 0,621 |

Текущая смесь даёт лучший знаковый Pearson r на каждом из четырёх блоков
целевого участка среди средних прогнозов пяти семейств. Новые модели также
уступают при исключении любого одного блока из оценки. Лучший одиночный
запуск нейросети на исторической проверке дал Pearson² 0,234. У всех девяти
одиночных нейросетевых запусков знак Pearson r на `late` отрицательный.

## Кейс 2

Обучение с расширенным пулом ВТД других труб. Каждая магистраль по очереди
целиком исключена из обучения. Признаки каждого примера ограничены его датой,
а признаки целевого участка ограничены 01.07.2022. Контроль — CatBoost на
относительной потере за год с балансировкой магистралей и кампаний.

| Модель | Средний знаковый r по MAIN | Средняя MAE, мм | MAIN-3, Pearson² | MAIN-3, MAE, мм |
| --- | ---: | ---: | ---: | ---: |
| **Текущий CatBoost** | **0,182** | 0,351 | **0,093** | 0,209 |
| LightGBM | 0,177 | 0,356 | 0,087 | 0,208 |
| XGBoost | 0,152 | 0,377 | 0,073 | 0,212 |
| LSTM | 0,058 | **0,341** | 0,002 | 0,259 |
| 1D-CNN | 0,069 | 0,412 | 0,012 | 0,409 |
| Transformer Encoder | 0,137 | 0,345 | 0,037 | 0,226 |

Средние сначала считаются по кампаниям, затем поровну по двум магистралям.
На MAIN-2 за июль 2022 года CNN улучшила Pearson² с 0,011 до 0,019. На
MAIN-3 её Pearson² ниже на 0,081, а поиск тонких ячеек дал 0% против 40%.
LightGBM ближе всего к текущей модели. Дополнительная проверка фиксированной
смеси `0,75 × CatBoost + 0,25 × LightGBM` по сохранённым прогнозам дала
0,0946 против 0,0925 по Pearson² на MAIN-3 и 0,1850 против 0,1823 по среднему r.
На самой большой кампании MAIN-2 Pearson² снизился с 0,0109 до 0,0091.
Такой небольшой и неодинаковый выигрыш не обосновывает замену модели.

## Как проверяли

У деревьев те же табличные признаки, обучающие цели и веса примеров, что в
контрольной модели каждого кейса. Ограничены глубина и число итераций. Нейросети
получают табличные признаки, девять соседних ячеек в пределах простого участка
и 24 тридцатидневных блока TECH до даты примера. Пространственное окно для кейса 1
использует прошлое ВТД. В кейсе 2 пространственное окно содержит профиль рельефа.
Статистики нормировки получены только из train. Пропуски имеют отдельную маску.
Для каждой архитектуры усреднены прогнозы трёх заранее заданных инициализаций
42, 73 и 101. Обучение на CPU, 48 эпох на вариант. По `late` параметры не подбирались.

Целевой участок кейса 2 имеет один ряд режима на всю трубу. У обучающих данных
есть только две независимо удерживаемые магистрали. Даже нейросети с локальным
окном ограничены доступным пространственным сигналом. Результаты относятся к
указанным архитектурам и режиму обучения. Точность на скрытых ВТД неизвестна.

Ссылки на используемые реализации: [PyTorch](https://docs.pytorch.org/docs/stable/nn.html),
[LightGBM](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRegressor.html) и
[XGBoost](https://xgboost.readthedocs.io/en/stable/python/python_api.html).

## Воспроизведение

Дополнительные зависимости нужны для сравнения. Используйте Python 3.12 и
окружение с достаточным местом для CPU PyTorch. Из корня проекта:

```powershell
python -m pip install -r requirements.txt -r requirements-final-round.txt
python -m pipetwin.pipeline prepare-cases --output artifacts/final-round-inputs
python -m pipetwin.final_round --prepared artifacts/final-round-inputs/case1/prepared.joblib --output artifacts/final-round-repeat
```

В полном запуске сохраняются все прогнозы, метрики отдельных и усреднённых
нейросетей и аудит обучения. Опубликованные CSV содержат компактное сравнение.
