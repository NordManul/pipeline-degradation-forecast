# Файл сдачи и проверки вариантов

[result.csv](result.csv) содержит 2 000 строк и ровно три колонки `id,segment_id,thickness_pred`.
Кейс 1 — 525 сегментов, смесь GAM/CatBoost 50/50 с локальным контекстом и строгой отсечкой.
Кейс 2 — 1 475 сегментов, CatBoost с балансировкой магистралей и кампаний.
Экспорт проверен по независимой сетке из паспортных длин, значения конечны и лежат в пределах
паспортного номинала. В доступных файлах не найден официальный `sample_result.csv`.
С ним нужно выполнить дополнительную сверку ключей и порядка при получении.

## Решения после проверки

| Изменение | Что получилось | Решение |
| --- | --- | --- |
| Знаковая дельта в мм вместо скорости потери в мм/год | На 508 исторических метках целевого участка Pearson² одинаков — 0,3033. Обучающих горизонтов здесь один. На late дельта дала 0,1256 против 0,0416 у скорости. | Сохраняем скорость в файле сдачи. Дельта интересна как диагностический кандидат, её выигрыш наблюдался на двух коротких соседних участках. |
| Неотрицательная потеря при прогнозе | На тех же 508 метках Pearson² падает до 0,2541, MAE растёт с 0,366 до 0,393 мм. При отсечке и обучающих дельт Pearson² 0,2768, MAE 0,408 мм. | Сохраняем знак наблюдаемого изменения. У 177 из 357 пар с якорем более поздний минимум оказался выше прошлого. ВТД сравниваются по ячейкам, где минимум может принадлежать разным точкам. |
| Clamp кейса 2 `[0.5×nominal, 1.05×nominal]` | Huber на ВТД 2018 выдаёт 89,80–92,22 мм для целевой трубы. Новый clamp даёт 4,725 мм во всех ячейках. У выбранного CatBoost на контрольных MAIN метрики неизменны. | Оставляем действующий предел `[0, nominal]`. Повышение потолка не возвращает сигнал, а нижний порог может скрыть тонкий участок. |
| Медиана и флаг для входов вне `[q01, q99]` | При старом обучении Huber исходный профиль становится 2,234–3,697 мм. Для текущего CatBoost на MAIN-3 Pearson² падает с 0,0925 до 0,0276, а MAE растёт с 0,209 до 0,225 мм. | Выброс Huber устраняется на входе, но перенос и ранжирование не достигают качества выбранной модели. CatBoost в сдаче без фильтра. |
| GAM только на режиме | Pearson² на исторических 508 ячейках падает с 0,2564 до 0,1406, на late растёт с 0,0199 до 0,0244. E02 на тех же очищенных входах даёт 0,1305 и MAE 0,282 мм на late. | Оставляем локальный контекст. E02 использует другую целевую величину и алгоритм, поэтому его выигрыш нельзя приписать одному удалению признаков. |
| Калибровка интервалов на late | Для текущей смеси покрытие на 53 поздних метках растёт с 71,7% до 77,4% при перекрёстной калибровке с исключением 100-метрового блока и буфером 100 м. Средняя ширина 1,114 → 1,043 мм. | Приводим эффект на защите как диагностический. Для строгого прогноза кейса 1 интервалы рассчитаны по OOF 2022 года, поскольку late — та же дата на MAIN-2. |

Разница между текущим значением GAM 0,0199 на late и опубликованным историческим
0,0419 связана с новым протоколом подготовки: современный GAM обучается только
на наблюдаемых якорях и использует текущий резервный прогноз. В таблице сравниваются
абляции внутри одного протокола. E02 — прямая Ridge-регрессия остаточной толщины
по прошлому замеру и режимным агрегатам. GAM только на режиме всё равно
вычитает прогнозную потерю из прошлого замера при восстановлении толщины.

В кейсе 2 проверка интервалов с исключением целого простого участка даёт 62,9%
на MAIN-2 и 77,7% на MAIN-3. Это показывает неодинаковый перенос оценки ошибки.
В [diagnostic_intervals.csv](diagnostic_intervals.csv) собраны эмпирические
P10–P90 для обеих труб, без гарантии 80% покрытия на скрытых ВТД. Точечные
прогнозы совпадают с `result.csv` с точностью до округления экспорта.
Интервалы и диагностика не участвовали в выборе моделей.

## Воспроизведение

Из корня репозитория. Сначала подготовить исходные входы и данные для сверки
кейса 1, затем получить два прогнозных профиля и собрать файл сдачи.

```powershell
python -m pipetwin.pipeline prepare-cases --output artifacts/submission-inputs
python -m pipetwin.pipeline case-benchmark --prepared artifacts/submission-inputs --output artifacts/submission-benchmark
python -m pipetwin.case1_heuristics --prepared artifacts/submission-inputs/case1/prepared.joblib --reference artifacts/submission-benchmark/case1 --output artifacts/submission-case1
python -m pipetwin.pipeline case2-transfer --output artifacts/submission-case2
python -m pipetwin.pipeline assemble-cases --case1 artifacts/submission-case1/forecast_provisional.csv --case2 artifacts/submission-case2/forecast.csv --output artifacts/submission-final/result.csv
python -m pipetwin.pipeline submission-checks --prepared artifacts/submission-inputs/case1/prepared.joblib --output artifacts/submission-checks-repeat
```

При наличии организаторского шаблона добавить `--template sample_result.csv`
к `assemble-cases`, указав новый путь для результата. Команда требует точного
совпадения ключей со своим паспортным расчётом и с шаблоном, затем сохраняет
порядок шаблона. В подготовленном файле 525 ячеек `1250022871` на 01.12.2023
и 1 475 ячеек `1250009583` на 01.07.2022.
